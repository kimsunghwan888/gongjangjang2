# 정부 보도자료 릴스 자동화

매일 16:00에 영상을 만들고, 16:30에 인스타그램·페이스북에 올립니다.

## 하루 흐름

| 시간 | 작업 | 프로그램 | 상태 |
|---|---|---|---|
| 16:00 | 정책브리핑에서 부동산·세금 보도자료 찾기 → 요약 → 음성·자막 → 15~25초 영상 | `make.js` | 작동 확인 |
| 16:30 | 인스타 릴스 + 페이스북 릴스 게시 | `post.js` | **키 필요 (아래)** |

- 결과물: `output\날짜\reel.mp4`, `caption.txt`(게시 문구), `meta.json`
- 기록: `logs\make.log`, `logs\post.log`
- 이미 쓴 자료는 `output\used.json`에 기록해 중복을 막습니다.
- 그날 자료가 없으면 최근 3일 이내 자료를 쓰고, 그것도 없으면 건너뜁니다 (옛 영상은 올리지 않음).

## 직접 해야 할 일 (인스타·페이스북 연결)

게시에는 Meta(페이스북) 승인 정보 3개가 필요합니다. 제가 대신 만들 수 없습니다.

1. 인스타그램을 **프로페셔널 계정**(비즈니스 또는 크리에이터)으로 바꾸고, **페이스북 페이지**와 연결
2. Meta 개발자 사이트(developers.facebook.com)에서 앱 만들기
3. 권한 허용: `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`
4. **오래 쓰는 페이지 토큰** 발급 → 윈도우 환경변수에 저장

| 환경변수 이름 | 내용 |
|---|---|
| `META_ACCESS_TOKEN` | 오래 쓰는 페이지 토큰 |
| `IG_USER_ID` | 인스타그램 비즈니스 계정 번호 |
| `FB_PAGE_ID` | 페이스북 페이지 번호 |

- 값은 파일에 적지 않습니다 (기존 API 키와 같은 방식).
- 화면 이름은 Meta 쪽 사정으로 바뀔 수 있습니다.
- 확인: `node post.js --dry-run` (게시하지 않고 점검만)

## 알아둘 점

- 컴퓨터가 켜져 있어야 실행됩니다. 꺼져 있으면 켠 뒤 바로 실행합니다.
- 요약은 Gemini 사용. 한도가 끝나면 `claude` 명령으로 대신합니다.
- 본문에 없는 숫자가 들어간 항목은 자동으로 뺍니다.
- 게시 문구에 출처(부처·날짜·원문 주소)를 항상 넣습니다.
- 시행착오: 정책브리핑 RSS는 2026-07-01 중단 → 목록 페이지를 직접 읽는 방식 사용.
- 시행착오: "전세계"가 "전세"로 잡힘 → 제목 규칙을 엄격하게 수정.
- 등록 다시 하기: `register-tasks.ps1` 실행. 멈추기: 작업 스케줄러에서 `week7-reels-make`, `week7-reels-post` 사용 안 함.
