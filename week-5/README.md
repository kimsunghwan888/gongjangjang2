## 2026년 10월 9일 — quest6 헬시 에이전트 리모컨

### 작업 대상

[헬시 에이전트 리모컨](quest6/README.md)

### 변경 내용

- 건강식품 리서치와 상세페이지 제작 에이전트를 원격 제어하는 모바일 대시보드(`index.html`)와 백엔드(`server.js`)를 만들었습니다.
- 이메일 매직 링크 로그인과 JWT 세션, 명령 큐, WebSocket 실시간 상태를 구현했습니다.
- 쿠팡 상위 상품, 원료 수입량, 홈쇼핑 편성표를 수집·정제해 수입 급증 × 홈쇼핑 편성 매칭 표를 만듭니다.
- 상품명, SEO 키워드 2개, 상세페이지 Markdown, 이미지 프롬프트를 생성하는 AI 레이어를 넣었습니다.
- 수입량은 공공데이터포털 무료 API와 연결할 수 있게 했고, 키가 없으면 가상 데이터를 씁니다.
- 대시보드를 백엔드에 연결하고, 개인용으로 메일 없이 바로 로그인되게 했습니다.

### 참고

- 쿠팡과 홈쇼핑은 가상 데이터이며, 쿠팡 차단 우회 요청(프록시, User-Agent 롤링)은 구현하지 않았습니다.
- `start.bat`을 더블클릭하면 서버(3100 포트)가 켜지고 브라우저가 열립니다.
- 이 폴더는 원래 `건강식품-에이전트-리모컨`이었고 `week-5/quest6`로 옮겼습니다.

## 2026년 10월 9일 — quest8 모의투자 자동 매매 에이전트

### 작업 대상

[YOU 모의투자 자동 매매 에이전트](quest8/README.md)

### 변경 내용

- 목업 대시보드를 FastAPI 서버와 연결해 실제 시세, 차트, 매매 로그를 5초 주기로 표시합니다.
- JWT 로그인과 회원가입을 추가했습니다. 이메일 아이디를 지원하고, 가입되지 않은 아이디로 로그인하면 가입 화면으로 안내합니다.
- 대화형 어시스턴트 YOU를 추가했습니다. 로그인 직후 먼저 인사하고 질문하며 에이전트를 켜고 끌 수 있습니다.
- 바탕화면 바로가기와 시작프로그램 등록으로 컴퓨터를 켜면 서버가 자동 실행됩니다.
- 에이전트 ON/OFF 상태를 저장해 서버를 재시작해도 유지합니다.

### 참고

- 배포는 하지 않았고 로컬 전용입니다.
- 이전 위치에서 폴더를 옮기면서 바탕화면과 시작프로그램 바로가기 경로도 새 위치로 고쳤습니다.

## 2026년 10월 8일 — 더블클릭 실행 문제 해결

### 작업 대상

[여성 다이어트 리서치 자동화](quest5/README.md)

### 문제

컴퓨터를 다시 켠 뒤 실행 파일을 더블클릭해도 리서치 화면이 열리지 않았습니다. 기존 배치파일은 서버를 백그라운드로 시작하기만 하고, 서버 준비 여부를 확인하거나 브라우저를 열지 않았습니다. 서버 실행에 실패해도 오류 내용을 확인하기 어려웠습니다.

### 변경 내용

- [자동 실행 배치파일](quest5/여기를_더블클릭하면_자동실행.bat)이 먼저 Node.js 설치 여부를 확인합니다.
- `http://127.0.0.1:3000/api/health`를 확인해 서버가 이미 실행 중이면 새 서버를 중복으로 시작하지 않습니다.
- 서버가 꺼져 있으면 백그라운드에서 시작하고, 최대 10초 동안 준비 상태를 확인합니다.
- 서버가 준비되면 리서치 페이지를 브라우저에서 엽니다.
- Node.js가 없거나 서버 시작이 실패하면 안내 메시지를 표시합니다. 서버 오류는 `data/server.log`에서 확인할 수 있습니다.
- [프로젝트 README](quest5/README.md)에 실행 방법과 문제 확인 방법을 반영했습니다.

### 확인 결과

- `node --check server.js`: 통과
- 더블클릭 배치파일 실행: 종료 코드 0
- 서버 상태 확인: `http://127.0.0.1:3000/api/health` 응답 HTTP 200

### 실행 방법

프로젝트 폴더에서 `여기를_더블클릭하면_자동실행.bat`을 더블클릭합니다. Node.js가 설치되어 있어야 하며, 화면이 열리지 않으면 `data/server.log`를 확인합니다.

## 2026년 10월 8일 — 키워드와 인기 댓글 리서치 추가

### 작업 대상

[여성 다이어트 리서치 자동화](quest5/README.md)

### 요청

기존의 인기 이유 10개 입력란을 없애고, 리서치 결과에서 영상별 키워드 1~3개와 조회수가 높은 키워드, 댓글 약 5개를 확인하고 싶었습니다.

### 변경 내용

- 화면과 서버에서 인기 이유 노트 입력·저장 기능을 제거했습니다.
- 영상별로 YouTube 공개 태그를 최대 3개까지 표시합니다. 태그가 비공개인 경우에는 제목의 해시태그와 단어를 대신 찾아 표시합니다.
- 조회수 상위 키워드 TOP 3을 추가했습니다. 키워드가 포함된 영상들의 조회수를 합산하며, 집계에 태그와 제목 중 무엇을 사용했는지도 구분합니다. 이 합계는 키워드가 조회수를 직접 발생시켰다는 뜻은 아닙니다.
- 각 영상마다 좋아요가 많은 댓글 최대 5개를 표시합니다. YouTube가 관련도순으로 반환한 공개 댓글 최대 100개를 가져와 좋아요 수로 다시 정렬합니다.
- 댓글이 비활성화됐거나 가져오지 못한 경우 화면에 상태를 표시합니다.
- 보고서 다운로드에 키워드 상위 3개, 영상별 키워드와 댓글을 포함했습니다.
- 서버 데이터를 기존 저장 형식에서 새 형식으로 읽을 수 있도록 처리하고, README에 키워드 집계와 API 할당량 안내를 추가했습니다.

### 확인 결과

- 실제 리서치 API 실행: 5천만 조회 이상 후보 10개 확인
- 결과 화면: 키워드 상위 3개와 영상별 키워드 표시 확인
- 댓글: 상위 10개 영상에서 총 50개를 가져와 좋아요 순으로 표시 확인
- 응답 데이터: 영상당 키워드 최대 3개, 댓글 최대 5개 확인
- 기존 인기 이유 노트 API: 제거되어 HTTP 404 응답
- `node --check server.js`, 에디터 문제 검사, `git diff --check`: 통과

### 주의 사항

YouTube에서 태그를 공개하지 않는 영상은 제목에서 키워드를 찾으므로, 이를 영상에 실제 등록된 태그와 혼동하지 않도록 구분해 표시합니다. 댓글 기능은 영상별 API 요청이 추가되어 YouTube Data API 할당량을 더 사용합니다. 댓글이 비활성화된 영상은 댓글 목록을 가져올 수 없습니다.
