# 여성 다이어트 리서치 자동화

YouTube Data API v3에서 여성 다이어트 관련 Shorts 후보를 검색하고, 조회수 5천만 이상·영상 길이 3분 이하인 콘텐츠를 상위 10개까지 저장합니다. 영상별 공개 태그 키워드와 좋아요가 많은 댓글 최대 5개도 함께 정리합니다.

## 시작하기

1. `.env.example`을 `.env`로 복사합니다.
2. `.env`의 `YOUTUBE_API_KEY`에 Google Cloud의 YouTube Data API v3 키를 입력합니다.
3. `여기를_더블클릭하면_자동실행.bat`을 더블클릭합니다. 서버가 준비되면 리서치가 자동으로 실행되고, 검색이 끝난 뒤 결과 화면이 열립니다.
4. 필요하면 화면에서 **7일 간격 자동 검색**을 켭니다.

Google Cloud Console에서 YouTube Data API v3가 프로젝트에 사용 설정되어 있어야 합니다. API 키는 저장소에 커밋하지 않습니다.
Node.js가 설치되어 있어야 합니다. `.env`에 API 키가 없으면 실제 검색은 시작되지 않으며, 배치 파일이 설정 방법을 안내합니다. 검색에 실패하면 배치 창에 오류가 표시됩니다. 이미 서버가 실행 중이어도 리서치 실행을 새로 요청합니다.

## 컴퓨터를 켤 때 자동으로 시작하기

아래 그림처럼 **바로가기 하나를 Windows 시작프로그램 폴더에 넣으면** 됩니다.

```text
컴퓨터 켜기
    ↓
시작프로그램 폴더가 열림
    ↓
[여기를_더블클릭하면_자동실행.bat] 실행
    ↓
리서치 서버 켜짐
    ↓
리서치 자동 실행
    ↓
검색 결과 화면 열기
```

1. 이 폴더의 `여기를_더블클릭하면_자동실행.bat`를 마우스 오른쪽 버튼으로 누릅니다.
2. **바로 가기 만들기**를 누릅니다.
3. 키보드에서 `Windows 키 + R`을 누릅니다.
4. 작은 창에 `shell:startup`을 입력하고 Enter를 누릅니다.
5. 방금 만든 바로가기를 열린 폴더 안으로 끌어다 놓습니다.
6. 다음부터 컴퓨터에 로그인하면 서버가 시작되고 리서치가 자동 실행된 뒤 결과 화면이 열립니다. 컴퓨터를 끄기 전까지 서버가 실행 중이어야 7일 간격 자동 검색도 동작합니다.

처음에는 `.env`에 API 키를 한 번만 설정해야 합니다. 시작프로그램 폴더에 바로가기를 넣으면 로그인할 때마다 검색하므로 YouTube Data API 할당량을 사용합니다. 7일 간격 자동 검색은 서버가 켜져 있는 동안 실행됩니다.

## 저장 방식

검색 결과와 7일 예약 상태는 `data/research-state.json`에 저장되어 서버를 재시작해도 유지됩니다. 영상별 키워드는 공개된 영상 태그에서 최대 3개를 가져오며, 태그가 비공개이면 제목의 해시태그와 단어를 사용한다고 표시합니다. 전체 키워드 TOP 3은 공개 태그를 우선하고 없을 때 제목 키워드를 사용해 해당 영상들의 조회수를 합산합니다. 이 합계는 키워드가 조회수를 직접 발생시켰다는 의미는 아닙니다. 댓글은 각 영상에서 YouTube가 관련도순으로 반환한 공개 댓글 최대 100개를 좋아요 순으로 정렬해 최대 5개를 표시합니다. 댓글이 꺼져 있거나 태그가 비공개인 영상은 해당 상태를 표시합니다. 상태 파일에는 API 키가 들어가지 않으며 로컬 운영 데이터이므로 Git에 올리지 않습니다.

## 제한

- YouTube 검색 API의 일일 할당량을 사용합니다.
- 댓글도 영상별로 조회하므로 리서치 실행 시 YouTube Data API 할당량을 추가로 사용합니다.
- 검색 결과는 Shorts 후보이며, YouTube API의 검색 조건과 영상 길이로 선별합니다.
- 실제 Shorts 여부와 키워드의 성과 연관성은 최종적으로 사람이 확인해야 합니다.
