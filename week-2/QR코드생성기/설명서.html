QR코드 생성기만드는 순서

만드는 순서 8단계

초록색 칸이 사람이 하는 일, 흰 칸은 조수가 하는 일입니다.

1
폴더 만들기앱이 살 집. "QR코드생성기 폴더 만들어줘"
2
무엇을 만들지 정하기크기 · 저장 방법 · 꾸밈. 여기서 90%가 결정됩니다.
3
한 문장으로 시키기처음엔 짧게. 보고 나서 고치는 편이 훨씬 쉽습니다.
4
파일 적기조수가 index.html 하나를 만듭니다. 1~2분.
5
더블클릭해서 확인폰 카메라로 비춰 보는 것이 진짜 시험입니다.
6
안 되면 증상만 말하기고치는 법은 몰라도 됩니다. "QR이 안 나와"
7
다듬기"색 바꿔줘" "더 크게" — 한 번에 완벽할 필요 없습니다.
8
git 저장 + GitHub 올리기찰칵(commit) → 금고에 맡기기(push)

3단계에서 쓴 문장

“글자나 인터넷 주소를 넣으면 QR코드가 나오고, 저장 버튼을 누르면 그림 파일로 내려받아지는 페이지를 index.html 하나로 만들어줘. 글자와 버튼은 크게.”

번호하는 일설명
1글자 넣기타이핑을 멈추면 곧바로 QR코드가 그려집니다. 최대 500자.
2크기 고르기작게 200 · 보통 320 · 크게 500. 인쇄해서 벽에 붙이려면 크게.
3QR코드 확인폰 카메라를 비추면 노란 알림이 뜹니다. 뜨면 성공.
4저장 또는 인쇄그림(PNG) · 문서(PDF) · 바로 인쇄 세 가지.

QR코드 생성기문제 해결

안 될 때

고치는 법은 몰라도 됩니다. 증상만 그대로 말하면 됩니다.

증상왜 그런가이렇게 말하세요
QR코드가 아예 안 나옴부품을 못 빌려옴 (인터넷 끊김)"QR코드가 안 나와"
폰이 못 읽음너무 작거나 화면이 어두움"QR코드를 더 크게 만들어줘"
저장이 안 됨저장 방식 문제"저장 버튼이 안 돼"
한글이 깨짐글자 방식(인코딩) 문제"한글도 되게 해줘"
글씨가 작음—"글자를 더 크게 해줘"
고친 게 화면에 안 보임브라우저가 옛날 것을 보여줌F5 또는 Ctrl+F5

이 앱만 다른 점 — 인터넷이 필요합니다

나이계산기·디데이계산기는 계산이 뺄셈뿐이라 인터넷 없이 됩니다. QR코드는 무늬 계산을 남의 부품에 맡기고, 그 부품을 인터넷 창고에서 빌려오기 때문에 처음 열 때 인터넷 연결이 있어야 합니다.
