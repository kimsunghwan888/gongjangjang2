무엇을 만들든 같은 5단계

QR코드든 계산기든, 순서는 언제나 똑같습니다.

  1. 폴더 하나 만들기앱이 살 집입니다. 바탕화면에 내앱 처럼.
  2. VSCode에서 그 폴더 열기파일 → 폴더 열기
  3. 조수 부르기터미널에 claude
  4. 하고 싶은 말 한국어로 적기다음 장의 문장을 그대로 붙여넣으셔도 됩니다.
  5. 생긴 index.html 더블클릭인터넷 창이 뜨면 완성입니다.
3과

만들 수 있는 여섯 가지

붉은 점이 많을수록 어렵습니다. 왼쪽 위부터 차례대로 하시면 됩니다.

나이 · D-day 계산기

생년월일을 넣으면 만 나이, 며칠 살았는지, 다음 생일까지 며칠인지 알려줍니다. 계산은 뺄셈 하나뿐이라 가장 쉽습니다.

이렇게 말하세요 — 생년월일을 넣으면 만 나이와 오늘까지 며칠 살았는지, 다음 생일까지 며칠 남았는지를 큰 글자로 보여주는 페이지를 만들어줘.

QR코드 생성기

글자나 인터넷 주소를 흑백 무늬 그림으로 바꿔 줍니다. 무늬 계산은 남이 만들어 둔 부품이 대신 해 줍니다. → 만들었습니다. 4과 참고

이렇게 말하세요 — 글자나 주소를 넣으면 QR코드가 나오고, 저장 버튼을 누르면 그림 파일로 내려받아지는 페이지를 만들어줘.

색상 팔레트

어울리는 색 다섯 개를 뽑아 줍니다. 색은 #AFCDE9 같은 번호로 적히고, 클릭하면 복사됩니다. 문서나 발표자료 색 고를 때 씁니다. → 만들었습니다. 5과 참고

이렇게 말하세요 — 스페이스바를 누르면 색 5개가 새로 바뀌고, 마음에 드는 색은 자물쇠로 고정하고, 클릭하면 색 번호가 복사되는 페이지를 만들어줘.

PDF 생성기

PDF는 어디서 열어도 모양이 안 망가지는 파일입니다. 글을 넣고 버튼 한 번이면 문서가 만들어집니다. → 만들었습니다. 6과 참고

이렇게 말하세요 — 글을 입력하면 저장 버튼 하나로 PDF가 만들어지는 페이지를 만들어줘. 한글 폰트 꼭 넣어줘.

짤(밈) 메이커

사진 위에 굵은 흰 글씨를 얹습니다. 컴퓨터 속 도화지 위에 그림을 그리는 방식입니다. 사진은 내 컴퓨터 안에서만 쓰이고 밖으로 나가지 않습니다.

이렇게 말하세요 — 사진을 고르면 위·아래에 글자를 넣고, 글자 크기를 조절해서 그림으로 저장되는 짤 만들기 페이지를 만들어줘.

React로 만드는 SPA

SPA는 화면이 깜빡이며 새로 열리지 않고 한 화면 안에서 슥슥 바뀌는 앱입니다. React는 화면을 레고 블록처럼 조각내는 방식이라, 앞의 다섯 개를 한 집에 모을 때 씁니다.

이렇게 말하세요 — 왼쪽에 메뉴가 있고 QR·PDF·짤·D-day·색상이 모두 들어있는 한 페이지 앱을 index.html 하나로 만들어줘.

PDF 만들 때 꼭 기억할 것 — “한글 폰트 꼭 넣어줘”라고 말하지 않으면 글자가 네모(□□□)로 깨져 나옵니다.
4과

QR코드 생성기

처음으로 남의 부품을 빌려 쓴 앱입니다. 그래서 앞의 둘과 성질이 다릅니다.

QR코드는 컴퓨터가 읽는 점자입니다

글자를 흑백 네모칸 무늬로 바꿔 놓은 것입니다. 모서리의 큰 네모 세 개가 “여기가 위쪽”을 알려주기 때문에 비뚤게 비춰도 읽힙니다. 글자가 길수록 무늬는 촘촘해집니다.

‘부품을 빌린다’는 것

부품= 남이 미리 만들어 둔 기능
어려운 말로 라이브러리라고 합니다. QR 무늬 계산처럼 까다로운 일은 직접 만들지 않고 빌려 씁니다.
인터넷 창고= cdnjs.cloudflare.com
부품이 쌓여 있는 곳입니다. 파일 맨 윗줄에서 이 창고 주소를 불러옵니다. QR 무늬용과 PDF용, 두 개를 빌렸습니다.
그래서 이 앱만 인터넷이 필요합니다 — 나이계산기·디데이계산기는 계산이 뺄셈뿐이라 부품이 없습니다. QR코드 생성기는 열 때마다 창고에서 부품을 빌려오므로, 인터넷이 끊기면 “부품을 가져오지 못했습니다”라고 나옵니다.

QR코드는 어두운 색과 흰 바탕의 차이로 읽힙니다. 색이 밝으면 휴대폰이 무늬를 구분하지 못합니다.

PDF에서 한글이 깨지지 않게 한 방법

PDF는 한글 글꼴이 없으면 글자가 네모(□□□)로 깨집니다. 그래서 종이 한 장을 통째로 그림으로 먼저 그린 뒤, 그 그림을 PDF에 넣었습니다. 화면에 보이는 그대로 나오므로 글꼴 문제가 아예 생기지 않습니다.

넣으면 안 되는 것 — 주민번호, 계좌·인터넷뱅킹 비밀번호. QR코드는 암호가 걸린 것이 아니라 글자를 무늬로 바꿔 놓았을 뿐이라, 누구나 비추면 그대로 보입니다.
이렇게 말했습니다 글자나 인터넷 주소를 넣으면 QR코드가 나오고, 저장 버튼을 누르면 그림 파일로 내려받아지는 페이지를 index.html 하나로 만들어줘. 글자와 버튼은 크게.

색상 팔레트

지금까지 만든 것 중 유일하게 무엇을 ‘만드는’ 도구가 아니라 ‘고르는’ 도구입니다.

쓰는 순서

  1. 스페이스바를 누른다색 5개가 통째로 새로 바뀝니다. 마음에 들 때까지 몇 번이고 누르세요. 오른쪽 위 [새로 뽑기] 버튼도 같은 일을 합니다.
  2. 마음에 드는 색은 자물쇠를 잠근다색 오른쪽 위 🔓 를 누르면 🔒 로 바뀝니다. 잠근 색은 스페이스바를 눌러도 그대로 있습니다.
  3. 색을 눌러 번호를 복사한다화면 아래에 “복사했습니다” 하고 알림이 뜹니다.
  4. 쓸 곳에 붙여넣는다Ctrl+V. 문서에 넣든, 저에게 시키든 똑같습니다.

자물쇠가 이 도구의 핵심입니다

5개가 한 번에 다 마음에 들 일은 거의 없습니다. 마음에 드는 것부터 하나씩 잠가 가며 좁혀 나가는 방식입니다.

색 번호가 뭔가요

#AFCDE9= 색의 주민번호
앞에서부터 두 자씩 빨강 · 초록 · 파랑이 얼마나 섞였는지를 적은 것입니다. 이 여섯 글자만 있으면 한글이든 파워포인트든 어디서나 똑같은 색이 나옵니다.

아무 색이나 뽑지 않습니다

무작위로 뽑으면 어울리지 않는 조합이 나옵니다. 그래서 네 가지 방식 중 하나를 골라 규칙대로 뽑습니다. 지금 어떤 방식으로 뽑았는지는 화면 위쪽에 나옵니다.

PDF 생성기

글을 넣으면 버튼 하나로 PDF 문서가 만들어집니다. 한글이 절대 깨지지 않게 만들었습니다.

쓰는 순서

  1. 제목을 넣는다이 제목이 그대로 파일 이름이 됩니다. → 2026년 가을 모임 안내.pdf
  2. 내용을 쓴다오른쪽 종이에 즉시 나타납니다. 보이는 그대로 저장됩니다.
  3. 글자 크기와 글꼴을 고른다작게 13pt · 보통 15pt · 크게 18pt  |  고딕 · 명조
  4. 저장 버튼을 누른다‘다운로드’ 폴더에 PDF가 생깁니다.

저장 버튼이 두 개인 이유

버튼한글글자 복사언제 쓰나
PDF로 저장안 깨짐안 됨거의 항상 이것 — 버튼 한 번이면 끝
인쇄로 저장안 깨짐됩니다받는 사람이 글을 복사해야 할 때

‘인쇄로 저장’은 창이 하나 뜹니다. 거기서 프린터 대신 “PDF로 저장”을 고르고 저장을 누르세요.

한글이 깨지지 않는 이유

왜 글꼴을 안 넣었나= 파일이 너무 큽니다
한글은 글자가 11,172자나 되어서 글꼴 파일 하나가 5~16MB입니다. PDF마다 이걸 넣으면 파일이 무거워지고, 앱을 열 때마다 한참 기다려야 합니다.
대신 쓴 방법= 종이를 그림으로 그린다
내 컴퓨터에 이미 있는 한글 글꼴로 A4 한 장을 통째로 그린 뒤 그 그림을 PDF에 넣습니다. 깨질 일이 원천적으로 없습니다.

알아서 해주는 것

여러 쪽길게 쓰면 다음 쪽으로 자동으로 넘어갑니다. ◀ ▶ 로 미리 넘겨볼 수 있습니다.
쪽 번호2쪽이 넘으면 아래 가운데에 1 / 3 이 자동으로 붙습니다.
줄 바꿈Enter를 누른 곳에서 줄이 바뀌고, 빈 줄도 그대로 남습니다.
자동 기억쓰던 글이 그대로 남습니다. 창을 닫아도 안 사라집니다.

8과

git 과 GitHub

둘은 다른 물건이 아닙니다. 같은 앨범이 두 군데 있는 것입니다.

git= 내 컴퓨터의 타임머신 사진첩
폴더를 고칠 때마다 그 순간을 사진으로 남겨 둡니다. 오늘 망가뜨려도 어제 사진으로 되돌리면 그만입니다. 이 사진첩은 내 컴퓨터 안에만 있습니다.
GitHub= 인터넷 금고
그 사진첩을 한 부 더 맡겨 두는 곳입니다. 컴퓨터가 고장 나도 안전하고, 남에게 링크로 보여줄 수 있습니다.
