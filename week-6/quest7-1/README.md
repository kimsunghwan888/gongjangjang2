# 6주차 작업 기록 (quest7-1 한 곳에 정리)

## 폴더 구성

- `server.js`, `public/index.html`, `setup.sql`, `.env` — Supabase 연동 쇼핑몰 (현재 버전)
- `screenshots/` — 테스트 캡처 화면
- `quest7-자체로그인/` — 이전 버전 (자체 JWT 로그인, 서버 메모리 저장)

## 2026년 10월 14일 작업

### 현재 버전 — Supabase 연동 쇼핑몰
- 프론트: Supabase Auth 회원가입·로그인, 세션 토큰을 요청마다 자동 첨부
- 백엔드: Supabase 토큰 검사, 상품·주문을 Supabase DB에서 읽고 쓰기, 내 주문만 필터
- 설정: `.env` (URL, 키), `setup.sql` (테이블 생성 + 가짜 상품 4개)
- 확인 완료: 상품 목록·상세 (DB 연결), 로그인 없는 요청 401, 본인 주문만 조회, 남의 주문 403, 결제하기 → 토스 결제창 열림 (690,000원, 129,000원)
- 미확인: 토스 카드 결제 끝까지 (휴대폰·생년월일 입력 단계에서 중단), 결제 후 "결제완료" 상태 변경

### 이전 버전 — 자체 로그인 쇼핑몰 (`quest7-자체로그인/`)
- 상품 상세 → [결제하기] → 서버 검증 → 토스 테스트 결제창 연동
- 주문 금액 서버 비교 (조작 시 400), 결제 후 토스 재조회 교차 검증
- 회원가입·로그인 (bcrypt 암호화, JWT), 본인 주문만 조회, 남의 주문 403
- 확인: 결제창 열림까지. 카드 결제 끝까지는 미완료

## 실행 방법

- 현재 버전: `.env` 확인 → Supabase에서 `setup.sql` 실행 → `npm install` → `npm start` → `http://localhost:3001`
- 이전 버전: `quest7-자체로그인` 폴더에서 `npm install` → `npm start`

## 남은 일

- 토스 카드 결제 끝까지 진행, 결제 후 마이페이지에서 "결제완료" 확인
- 테스트 계정 2개와 테스트 주문 정리 (Supabase 대시보드)
- 노출된 Secret 키 재발급 후 `.env` 교체

## 시행착오

- 서버를 중복 실행해서 3001 포트 충돌 → 기존 서버 종료 후 다시 실행
- `.env` 자리표시를 한글로 적어서 헤더 오류 → 영문 자리표시로 변경
- 브라우저가 옛 화면을 캐시 → 주소 뒤에 `?fresh=1`을 붙여 새로 열기
- `example.com` 이메일은 Supabase가 거절 → 관리자 API로 테스트 계정 생성
